## 🔬 Final Year Project — ParkiFy

<img align="right" width="280" src="https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif"/>

**An AI-Powered Smart Parking Management System**

**The Problem:** Manual parking entry/exit tracking is slow and error-prone — no automated vehicle recognition, no digital payment trail, and no real-time visibility for admins when something goes wrong.

**What I Built:** A full-stack system pairing a **React** frontend (web + mobile-friendly) with a **Node.js/Express** REST API and **MongoDB** database, covering vehicle registration, login, wallet balance, parking history, and unique QR codes for every vehicle.

**The Model:** Integrated a **YOLOv8** object-detection model for automatic number-plate recognition (ANPR) at the entry gate, matched against each vehicle's QR code — tuned to hold up across varying lighting and camera angles.

**Automation:** Exit processing automatically calculates parking duration, deducts wallet balance, and fires payment + notification events in real time. Real-time push notifications cover entry, exit, low balance, and overstay warnings.

**Admin Side:** A dashboard for real-time logs, user management, payments, fraud alerts, and reporting.

**Testing:** End-to-end manual testing of the entry → detection → wallet-deduction → exit flow, Postman testing of all REST endpoints, and accuracy checks of the YOLOv8 plate-detection model against sample gate-camera footage under different lighting conditions.

**[View Repository →](https://github.com/nosheenfatima025/Parkify)**
